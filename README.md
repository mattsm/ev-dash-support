# EV Dash support

Bug reports, questions and feature requests for **EV Dash**, the Android and Android Auto app by M4 Embedded, LLC that shows live battery, charging and drive data from Hyundai, Kia and Genesis EVs.

- About the app: https://mattsm.github.io/m4embedded/ev-dash/
- Privacy policy: https://mattsm.github.io/m4embedded/ev-dash/privacy.html

## Get help

[Open an issue](https://github.com/mattsm/ev-dash-support/issues/new/choose) and pick a form. Search the [existing issues](https://github.com/mattsm/ev-dash-support/issues?q=) first in case someone already asked.

**Issues are public.** Don't post your VIN, your location, or the "Share diagnostics" file (it contains your VIN). If a diagnostics file would help, say so in the issue and we'll arrange a private way to send it.

The app's source code is not in this repository.
